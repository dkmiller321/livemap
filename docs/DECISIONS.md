# DECISIONS.md

Claude Code records here every assumption it made where the PRD or the tests were silent, every dependency added inside `examples/`, the hookup settings it verified against the installed instrumentation packages (with their versions), and anything deliberately left out of scope. One dated line or short paragraph per decision, newest last.

- 2026-10-09 — **Toolchain.** Node 22.17, npm 10.9, Python 3.13.5 (`python`). `python3` on this machine is 3.8.10, below the 3.10 floor, so `npm run examples:setup` tries `PYTHON_BIN`, then `python3`, `python`, `py -3`, and uses the first that is 3.10 or newer.
- 2026-10-09 — **Package versions.** `protobufjs` 8.8 (latest; `protobufjs-cli` 2.7 needs protobufjs 8 as a peer, so 7.x could not be used). `typescript` 7.0 (the native compiler) runs `tsc --noEmit` with `checkJs`; a probe file with a type error confirmed it checks `.mjs` and JSDoc. `@playwright/test` 1.64 with its Chromium build.
- 2026-10-09 — **Protocol definitions.** `src/otlp/descriptor.json` is generated with `pbjs` from opentelemetry-proto v1.11.1 (trace, logs, common, resource and the two collector services). The `.proto` sources live in `src/otlp/proto/` with their Apache-2.0 licence and are excluded from the npm package; `npm run proto:gen` regenerates the descriptor.
- 2026-10-09 — **`span()` default kind.** E2E_TESTS.md 1.3 does not name the default span kind. It is INTERNAL, as in OpenTelemetry. Fixture rows that describe a client call (`kinds` 02, 03, 08, 09 and the legacy HTTP client 0a) are built as CLIENT.
- 2026-10-09 — **HTTP spans that are neither SERVER nor CONSUMER** (CLIENT, INTERNAL, PRODUCER, UNSPECIFIED) follow the client pairing rules. An HTTP client span that names no host goes to an external node called `unknown` after its wait.
- 2026-10-09 — **Server span whose parent is not a client call.** If the parent has arrived but is not an HTTP client span, the call is drawn from the parent's service when that differs, otherwise from Outside.
- 2026-10-09 — **The "same call seen twice" rule while the parent is missing.** A client span to an unknown address waits up to 300 ms for either its server span or its parent; if the parent turns out to be an LLM span in the same service, the client span is hidden.
- 2026-10-09 — **LLM node without a provider.** An LLM span with no provider attribute is drawn to its host's node, or to a node called `llm`.
- 2026-10-09 — **Extra event-stream events.** Besides the PRD's `snapshot`, `span`, `node`, `edge`, `node-removed` and `clear`, the stream sends `counts` (rolling 60 s node counts and edge count/median, computed in the process) and `trace` (a trace received new spans or log content, so an open waterfall or detail panel refetches). A late pairing re-sends `span` for the corrected row.
- 2026-10-09 — **Log record bodies (E2E-27).** The test posts bodies the way SDKs do, as OTLP `kvlistValue`. The receiver also accepts a `stringValue` holding JSON.
- 2026-10-09 — **Particle merging when no particle shares the edge (M6).** At the 150 cap a new span merges into the newest particle on its edge. If its edge has none, the oldest particle in flight is ended early and the new one starts, so `particlesSpawned + particlesMerged` always equals the drawn calls.
- 2026-10-09 — **Feed row time** is the span's start time in the browser's local time zone.
- 2026-10-09 — **E2E-01 non-loopback check.** On Windows a refused connect is retried for about 2 s before `ECONNREFUSED` (measured 2.05 s to 10.2.0.2), so the helper waits up to 6 s for the refusal. The assertion is unchanged.
- 2026-10-09 — **`LIVEMAP_BIN` pointing at an npm `.bin` shim.** On Windows the shim is a `.cmd` file, which Node will not spawn without a shell, and a shell would swallow the SIGINT the specs send. The helper runs the installed package's own `bin/livemap.mjs` with Node instead, which is the same file the shim calls.
- 2026-10-09 — **Node hookup, verified.** `@opentelemetry/auto-instrumentations-node` 0.81.0 already includes `@opentelemetry/instrumentation-openai` 0.21.0 (supports `openai >=4.19.0 <7`; the example uses openai 5.23.2), so no separate setup file is needed. It runs the SDK request inside the LLM span's context (`context.with`), so the HTTP child is hidden. Content capture is `OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=true` and arrives as log records (`event.name` attribute) through `OTEL_LOGS_EXPORTER=otlp`; sdk-node 0.223.0 reads that variable. `OTEL_BLRP_SCHEDULE_DELAY=200` matches the span delay.
- 2026-10-09 — **Node resource detectors.** The default detector set probes cloud metadata endpoints; off the cloud that delayed the example's start by about 10 s and logged `MetadataLookupWarning`. The example scripts set `OTEL_NODE_RESOURCE_DETECTORS=env,host,os,process,serviceinstance` (start-up 1.3 s).
- 2026-10-09 — **Python hookup, verified.** distro 0.66b1, exporter 1.45.1, openai-v2 2.4b0: `OTEL_SEMCONV_STABILITY_OPT_IN=gen_ai_latest_experimental` + `OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=span_only` put `gen_ai.input.messages` / `gen_ai.output.messages` on the span, exactly as the kit said.
- 2026-10-09 — **Python pins in `examples/python-app/requirements.txt`.** `openai<3`: openai 3.28 switched to `httpx2` and openai-v2 2.4b0 skips itself with "No module named 'httpx'". `opentelemetry-util-genai<1.2`: 1.2b0 renamed `opentelemetry.util.genai.instruments`, which openai-v2 2.4b0 imports, so it skipped itself again. Both were found from the loader's DEBUG log.
- 2026-10-09 — **SQLite in the Python example uses a cursor.** The sqlite3 instrumentation traces cursor calls; `Connection.execute()` runs in C and is invisible. The app uses `db.cursor().execute(...)`; still no OpenTelemetry in app code. Documented in `docs/hookups/python.md`.
- 2026-10-09 — **`opentelemetry-instrument` on Windows.** It ends in `os.execl`, which on Windows starts uvicorn as a new process and exits 0, orphaning the server (seen: the examples script reported "python-example exited (0)" while uvicorn kept port 4502). On Windows `npm run example:python` does what the launcher does (its `auto_instrumentation` folder and the working directory first on `PYTHONPATH`) and runs uvicorn directly; elsewhere it uses `opentelemetry-instrument`.
- 2026-10-09 — **Examples dependencies** (all inside `examples/`): node-app `express` 5, `openai` 5, `@opentelemetry/api`, `@opentelemetry/auto-instrumentations-node` 0.81; python-app `fastapi`, `uvicorn`, `openai<3`, `opentelemetry-distro`, `opentelemetry-exporter-otlp-proto-http`, `opentelemetry-instrumentation-openai-v2`, `opentelemetry-util-genai<1.2`, plus what `opentelemetry-bootstrap -a install` adds.
- 2026-10-09 — **Example metrics.** Metrics export is left at the SDK default, so the examples also exercise `POST /v1/metrics` (accepted and discarded).
- 2026-10-09 — **A client span that arrives after its server span was drawn from Outside.** The PRD covers the server waiting 300 ms and then being drawn from Outside, but not its client arriving later. That happened every time with the browser example: the fetch instrumentation waits ~300 ms for resource timing before ending its span. Livemap now treats it like the late pairing the PRD already corrects: the client is drawn, the server's row is taken back (`span-removed`), and an edge or node nothing else uses is removed (`edge-removed`, `node-removed`). The client is drawn first so the shared callee node keeps its slot. Nodes and edges count their uses to decide this.
- 2026-10-09 — **Browser example resource.** `WebTracerProvider({resource})` replaces the default resource, which drops `telemetry.sdk.language=webjs`; the setup merges with `defaultResource()`. Recorded in `docs/hookups/browser.md`.
- 2026-10-09 — **Browser example dependencies** (inside `examples/browser-page`): `@opentelemetry/api`, `sdk-trace-web` 2.12, `resources` 2.12, `exporter-trace-otlp-http` 0.223, `instrumentation-fetch` 0.223, `context-zone` 2.12, `esbuild` 0.28, plus `@opentelemetry/instrumentation` 0.223 for `registerInstrumentations`.
- 2026-10-09 — **Scroll hold (F5).** The feed counts as scrolled down when `scrollTop > 2`. Held rows wait in order behind the pill (at most 500); scrolling back to the top or clicking the pill inserts them. `stats().rows` counts rows on the page, not held ones.
- 2026-10-09 — **Pause (F6).** While paused the page queues every event except `snapshot` and `clear` and freezes particles in place; Resume replays the queue in order. A clear while paused drops the queue.
- 2026-10-09 — **Node and edge filters (M10).** Clicking a node shows rows that start or end at it; clicking an edge shows rows along it. The chip reads the node id, or `source → target` for an edge.
- 2026-10-09 — **API Host check.** The page server on 4400 answers only requests whose Host is `127.0.0.1:<port>` or `localhost:<port>`, so a web page cannot read the API through DNS rebinding. The receiver accepts any Host because SDKs may use either name.
